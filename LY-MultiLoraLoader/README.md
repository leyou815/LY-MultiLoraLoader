# LY 多LoRA加载器（6槽位）

一个 ComfyUI 自定义节点：**在一个节点里同时加载最多 6 个 LoRA**，每个 LoRA 槽位都有独立的**启用开关**（点击开启/关闭）、**类型**（默认 / 风格 / 人物）和**强度**。

## 这个节点做什么

以前接 6 个 LoRA 要在画布里摆 6 个 "Load LoRA" 节点串成一长串。现在只需要一个节点：

- **6 个槽位**，每个槽位 4 个控件：
  - `LoRA N`：从你的 `models/loras` 文件夹里选 LoRA（不用就不选）
  - `LoRA N 启用开关`：**点击开启 / 关闭**，关闭的槽位直接跳过，不加载、不占显存
  - `LoRA N 类型`：默认 / 风格 / 人物（下面有对照表）
  - `LoRA N 强度`：这个 LoRA 的浓度（默认 0.8）
- 多个 LoRA **按槽位顺序叠加**（1 → 2 → 3 → …），和手动串一串 Load LoRA 节点效果一致
- 节点多输出一个 `loaded_loras` 文本，跑图时能看到本次实际加载了哪几个 LoRA、类型和实际强度，方便排查
- 前端做了增强：**关闭的槽位会变灰、标签会标"（已关闭）"**；把一个还没选 LoRA 的空槽打开时，会自动帮你选中列表里的第一个 LoRA

## 类型对照表（重点）

不用再手动填文本强度了，选类型就行：

| 类型 | 模型强度 | 文本强度 | 什么时候用 |
|---|---|---|---|
| **默认** | = 你填的强度 | = 你填的强度（同步） | 不确定是什么类型时的通用选择 |
| **风格** | = 你填的强度 | **固定 0** | 画风、质感、光影、滤镜类 LoRA。文本侧不加权，避免它的触发词污染你的提示词 |
| **人物** | = 你填的强度 | **固定 1.0** | 角色 / IP / 特定长相 LoRA。文本侧满权重，触发词才能完整生效、长相才立得住 |

> 想改回"两边都手动控制"的话，选**默认**就是原来那个行为。

## 安装（不会弄脏系统）

1. 找到你的 ComfyUI 目录下的 `custom_nodes` 文件夹
   （一般就在 `ComfyUI/custom_nodes`；秋叶整合包在 `ComfyUI/custom_nodes` 里同理）
2. 把整个 `LY-MultiLoraLoader` 文件夹复制进去，最终路径长这样：
   ```
   ComfyUI/custom_nodes/LY-MultiLoraLoader/__init__.py
   ComfyUI/custom_nodes/LY-MultiLoraLoader/web/js/ly_multilora.js
   ```
3. 重启 ComfyUI（浏览器页面也刷新一下）

卸载 = 删掉这个文件夹，其余什么都不用动。

## 使用

1. 画布双击搜索 `LY` 或 `多LoRA`，添加 **「LY 多LoRA加载器（6槽位）」** 节点
2. `model`、`clip` 接到你的 Checkpoint Loader 后面（原来接 Load LoRA 链的位置）
3. 每个要用的 LoRA：选文件 → 把启用开关点成 **启用** → 选类型 → 调强度
4. 不用的槽位保持开关关闭即可，不影响其他槽位
5. `loaded_loras` 输出可以接一个「显示文本」节点，随时查看本次实际加载了什么

## 常见问题

- **下拉列表里没有我的 LoRA**：确认文件放在 `ComfyUI/models/loras` 里（子文件夹也可以，会显示成 `子文件夹/文件名`），放好后重启 ComfyUI
- **找不到节点**：确认文件夹层级没套错（`custom_nodes/LY-MultiLoraLoader/__init__.py` 必须直接存在，不能是 `custom_nodes/LY-MultiLoraLoader/LY-MultiLoraLoader/__init__.py`）
- **开关没有变灰效果**：核心功能（关闭即跳过）不依赖前端脚本，任何版本都生效；变灰是界面美化，老版 ComfyUI 可能只显示标签不带灰显
- **报错找不到 LoRA 文件**：多半是 LoRA 文件被移动或改名了，在节点里重新选一次即可
