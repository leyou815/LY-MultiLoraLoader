# LY 多LoRA加载器（6槽位）

一个 ComfyUI 自定义节点：**在一个节点里同时加载最多 6 个 LoRA**，每个槽位都有独立的**启用开关**（点击开启/关闭）、**类型选择**（默认 / 风格 / 人物）和**强度**。

不再需要把 6 个 "Load LoRA" 节点串成一长串——一个节点搞定，关闭的槽位不加载、不占显存。

---

## ✨ 功能特性

- **6 个独立槽位**，每个槽位 4 个控件：LoRA 选择 → 启用开关 → 类型 → 强度
- **启用开关**：点击开启/关闭，关闭的槽位直接跳过，不读文件、不占显存
- **类型一键适配**：不用再手动算文本强度，选类型就行（见下方对照表）
- **按顺序叠加**：多个 LoRA 按 1 → 6 顺序生效，与手动串 Load LoRA 节点链效果一致
- **加载报告**：额外输出 `loaded_loras` 文本，本次实际加载了哪些 LoRA、什么类型、什么强度，一目了然
- **界面增强**：全中文标签；关闭的槽位自动变灰并标注"（已关闭）"；打开没选 LoRA 的空槽时自动帮你选中第一个 LoRA

## 📋 类型对照表

| 类型 | 模型强度 | 文本强度 | 什么时候用 |
|---|---|---|---|
| **默认** | = 滑块值 | = 滑块值（同步） | 拿不准时的通用选择 |
| **风格** | = 滑块值 | **固定 0** | 画风、质感、光影、滤镜类 LoRA。文本侧不加权，避免触发词污染提示词 |
| **人物** | = 滑块值 | **固定 1.0** | 角色 / IP / 特定长相类 LoRA。文本侧满权重，触发词才能完整生效、长相立得住 |

> 想回到"两边都跟滑块走"的原始行为，选**默认**即可。

## 📦 安装方法（三选一）

### 方式一：ComfyUI Manager 安装（推荐，最省事）

1. 打开 **ComfyUI Manager** → **Custom Nodes Manager**
2. 点 **Install via Git URL**，粘贴：
   ```
   https://github.com/leyou815/LY-MultiLoraLoader
   ```
3. 点安装，完成后**重启 ComfyUI**（浏览器页面也刷新一下）

> 以后更新：Manager 里找到本节点点 **Update** → 重启即可。

### 方式二：git clone（命令行）

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/leyou815/LY-MultiLoraLoader.git
```

然后重启 ComfyUI。以后更新：

```bash
cd ComfyUI/custom_nodes/LY-MultiLoraLoader
git pull
```

### 方式三：网页下载 ZIP（不用装任何工具）

1. 打开本仓库页面 → 绿色 **Code** 按钮 → **Download ZIP**
2. 解压后把得到的文件夹（`LY-MultiLoraLoader-main`）整个放进：
   ```
   ComfyUI/custom_nodes/
   ```
   放完的最终路径长这样（`__init__.py` 必须直接在这个文件夹的根下，文件夹叫什么名字无所谓）：
   ```
   ComfyUI/custom_nodes/LY-MultiLoraLoader-main/__init__.py
   ComfyUI/custom_nodes/LY-MultiLoraLoader-main/web/js/ly_multilora.js
   ```
3. 重启 ComfyUI

> 更新：重新下载 ZIP，删掉旧文件夹、放入新的即可。

**卸载**：删掉 `custom_nodes` 里对应的文件夹，其余什么都不用动。

## 🖱 使用方法

1. 画布空白处双击，搜索 `LY` 或 `多LoRA`，添加 **「LY 多LoRA加载器（6槽位）」** 节点
2. `model`、`clip` 接到 Checkpoint Loader 后面（原来串 Load LoRA 链的位置）
3. 每个要用的 LoRA：选文件 → 点亮**启用开关** → 选**类型** → 调**强度**（默认 0.8）
4. 不用的槽位保持开关关闭即可，互不影响
5. （可选）`loaded_loras` 输出接一个「显示文本」节点，跑图时随时查看本次实际加载情况：
   ```
   风格包 [风格] m:0.80 / c:0.00 + 人物包 [人物] m:0.60 / c:1.00
   ```

## ❓ 常见问题

- **下拉列表里没有我的 LoRA**
  确认文件在 `ComfyUI/models/loras` 里（子文件夹也行，会显示成 `子文件夹/文件名`），放好后重启 ComfyUI。

- **装完找不到节点**
  检查文件夹层级：`__init__.py` 必须直接在 `custom_nodes/某文件夹/` 的第一层。如果你是 Download ZIP 解压的，确认没有套两层文件夹；如果是从旧版手动复制的，确认没有把整个外层文件夹拖进去。

- **开关关闭后槽位没有变灰**
  变灰是界面美化，依赖较新的 ComfyUI 前端。核心功能（关闭即跳过）不依赖前端脚本，任何版本都生效——升级 ComfyUI 前端后即可看到灰显效果。

- **报错找不到 LoRA 文件**
  多半是文件被移动或改名了，在节点下拉框里重新选一次即可。

- **旧工作流里的节点强度还是 1.0**
  工作流保存的是当时的数值，不会跟随新版默认值。删掉旧节点换新的，或手动改成 0.8。
